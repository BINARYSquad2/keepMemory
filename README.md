# KeepMemory

Личный арт-дневник, который превращает текст о дне, фотографию и выбранный музыкальный фрагмент в оформленное воспоминание.

## Запуск Go API

Из корня репозитория в PowerShell:

```powershell
Set-Location backend
$env:DATABASE_URL = "postgres://postgres:your_password@localhost:5432/keepmemory?sslmode=disable"
$env:JWT_SECRET = "replace-with-a-long-random-development-secret"
go run .
```

Замените `your_password` на пароль PostgreSQL. База `keepmemory` должна быть заранее создана; при запуске API проверит соединение и создаст таблицы `users` и `days`. pgAdmin — это клиент управления, сам сервер PostgreSQL должен быть запущен.
Если появляется `SQLSTATE 28P01`, PostgreSQL отклонил логин: проверьте роль, пароль, адрес и порт в `DATABASE_URL` по настройкам подключения сервера в pgAdmin. Не отправляйте пароль в чат.
Сервер слушает порт `8080`; проверить его можно по адресу `http://localhost:8080/health`.

## Запуск мобильного приложения

В отдельном PowerShell:

```powershell
Set-Location mobile
npm install
npx expo start
```

Для Android-эмулятора приложение по умолчанию обращается к `http://10.0.2.2:8080`.
Для iOS Simulator и веб-версии используется `http://localhost:8080`.
На физическом телефоне задайте адрес компьютера в локальной сети перед запуском Expo:

```powershell
$env:EXPO_PUBLIC_API_URL = "http://192.168.1.10:8080"
npx expo start
```

Замените IP на адрес компьютера, где запущен Go API. Телефон и компьютер должны быть в одной сети; порт `8080` должен быть доступен через брандмауэр.

## Подключённые API

- `POST /api/auth/register` и `POST /api/auth/login` — регистрация/вход и JWT.
- `GET /api/profile` и `PATCH /api/profile` — чтение и изменение профиля.
- `GET /api/tracks/search?q=...` — поиск треков с доступным preview через iTunes.
- `POST /api/days`, `GET /api/days`, `GET /api/days/:id` — создание, архив и просмотр записи.

Защищённые маршруты используют заголовок `Authorization: Bearer <token>`. Мобильное приложение хранит JWT в SecureStore на iOS/Android и в localStorage в браузере.

## Текущее хранение и ограничения

При запуске Go API подключается к PostgreSQL и создает таблицы, если их еще нет. Регистрация, вход, профиль и записи дней читаются из PostgreSQL и сохраняются в нем. Для теста всего API с PostgreSQL выполните `go test ./...` из папки `backend`; тест берет `DATABASE_URL` из окружения или `backend/.env`, создает уникальные тестовые записи и удаляет их после завершения. URI фотографии сохраняется в записи, но сами байты файла не загружаются на сервер, поэтому изображение может стать недоступным после удаления локального файла или открытия записи на другом устройстве.

Генерация оформления и названия папки выполняется детерминированными правилами Go API: сигналы из текста дня важнее метаданных трека, а энергия музыки управляет скоростью анимации. Это эвристики, не AI-промпт. Интеграции с Gemini/TTS, извлечения палитры из пикселей фото, объектного хранилища и подготовки APK в проекте пока нет.
