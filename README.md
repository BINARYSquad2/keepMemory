# KeepMemory

KeepMemory — личный арт-дневник: запись о дне, фотографии и выбранная песня собираются в оформленную страницу воспоминания.

## Возможности

- Создание записи из текста (10–4000 символов), альбома до 6 фотографий и песни.
- Поиск треков через iTunes Search API; доступен предварительный фрагмент, если он предоставлен iTunes.
- Четыре художественных режима, палитра, темп анимации, подпись и настроение. Локальный рецепт работает всегда; Gemini используется только при настроенном ключе и явном согласии пользователя для конкретной записи.
- Архив с группировкой по неделям, поиском и фильтрацией по настроению.
- Аккаунт, редактируемый профиль, удаление записей и ручной ZIP-экспорт данных с фотографиями.
- Просмотр и прослушивание воспоминания, экспорт карточки в PNG через системное меню iOS/Android.
- Локальная озвучка записи системным голосом устройства; текст не отправляется в облако для этой функции.

Фото в Gemini не отправляются: сервер локально анализирует цвет первого загруженного кадра. Только при явном согласии модели передаются текст записи, часть данных профиля и недавней истории, трек и извлечённые цвета. Фото выдаются через временные ссылки, проверяющие владельца записи; `/uploads` не является публичным маршрутом. Подробнее — в [документации о визуальной системе](docs/visual-system.md) и [потоках данных](docs/architecture.md).

## Состав проекта

- `mobile/` — приложение на React Native, Expo Router и TypeScript.
- `backend/` — REST API на Go, Fiber и PostgreSQL.
- `docs/` — OpenAPI-контракт и техническая документация. Начните с [индекса документации](docs/README.md).

## Быстрый запуск

Требуются Go версии, совместимой с `backend/go.mod` (указана `1.26.5`), Node.js/npm и PostgreSQL. Сначала создайте пустую базу данных `keepmemory`, затем создайте локальный `backend/.env`:

```env
PORT=8080
DATABASE_URL=postgres://postgres:<password>@127.0.0.1:5432/keepmemory?sslmode=disable
JWT_SECRET=<long-random-secret>
# Необязательно: вызов Gemini требует отдельного согласия в приложении.
GEMINI_API_KEY=<gemini-api-key>
# Необязательно; по умолчанию задаётся сервером.
GEMINI_MODEL=<model-name>
```

Не добавляйте реальные ключи и пароли в Git. `.env` и файлы окружения игнорируются Git.

В первом терминале PowerShell:

```powershell
Set-Location C:\path\to\KeepMemory\backend
go run .
```

Сервер создаёт необходимые таблицы при старте и по умолчанию слушает порт `8080`. Проверка процесса: `http://localhost:8080/health`; readiness с проверкой БД: `http://localhost:8080/health/ready`.

В другом терминале:

```powershell
Set-Location C:\path\to\KeepMemory\mobile
npm ci
npx expo start
```

Для устройств в одной локальной сети задайте URL API при старте Metro:

```powershell
$env:EXPO_PUBLIC_API_URL = "http://192.168.1.10:8080"
npx expo start
```

Замените адрес на IP компьютера с API. Значение по умолчанию в приложении: `http://10.0.2.2:8080` для Android-эмулятора и `http://localhost:8080` для iOS Simulator/веба. Подробные инструкции, тестирование и переменные окружения описаны в [настройке проекта](docs/configuration.md).

Для Railway, постоянного Volume, защиты медиа и дальнейшей сборки APK следуйте разделу о Railway в [настройке проекта](docs/configuration.md). `GET /api/backup` — ручной экспорт, поэтому включите также резервные копии PostgreSQL и тома на платформе.

## Проверки

Из `backend/` запустите `go test ./...`. Интеграционный тест пропускается, если `DATABASE_URL` не задан; при настроенной PostgreSQL он проверяет регистрацию, профиль и сценарий записей.

Из `mobile/` запустите `npx tsc --noEmit` для проверки TypeScript. Для запуска приложения используйте `npx expo start`.
