# Документация KeepMemory

Документация описывает поведение, реализованное в текущем коде проекта.

## Навигация

- [Архитектура и потоки данных](architecture.md) — устройство приложения и путь записи от формы до архива.
- [REST API](api.md) — маршруты, авторизация, форматы запросов и ограничения.
- [OpenAPI 3.1](contract.json) — машиночитаемая спецификация API.
- [Модель данных и хранение](data-model.md) — PostgreSQL, файлы и особенности синхронизации.
- [Настройка и запуск](configuration.md) — переменные окружения, локальный запуск и проверки.
- [Визуальная система](visual-system.md) — режимы оформления, подбор палитры и генерация атмосферы.

## Границы документации

Документы не заменяют конфигурацию развертывания PostgreSQL или хранилища файлов. Backend создаёт таблицы при запуске, но сама база данных должна быть создана заранее. Загруженные изображения хранятся в файловой системе backend; для постоянного размещения в облаке каталогу `uploads` нужен постоянный диск или отдельное файловое хранилище.

OpenAPI-контракт и описания проверены по текущим обработчикам в `backend/`. Если API меняется, обновляйте одновременно код, `contract.json` и [описание API](api.md).
